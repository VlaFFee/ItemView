# Item Inspector — Forge 1.20.1 (47.3.0)

Креатив-предмет **«Экспонат»**: ПКМ открывает экран «Осмотр предмета» — слева 3D-предмет, который можно
крутить, справа панель с названием и описанием. Стиль тот же, что в моде на записки.

## Сборка через GitHub
1. Создай пустой репозиторий на GitHub.
2. Залей в него содержимое этой папки (корень репозитория = папка с `build.gradle`).
3. Вкладка **Actions** -> последний запуск **Build mod** -> внизу **Artifacts** -> `itemview-jar`.
4. Из архива достань `itemview-1.0.0.jar` и положи в `mods` — **и на сервер, и каждому игроку** (Forge 1.20.1).

## Локально
Нужны Java 17 и Gradle 8.1.x: `gradle runClient` / `gradle build`.

## Как сделать описание (креатив)
1. Возьми «Экспонат» из вкладки креатива «Осмотр предметов».
2. ПКМ — откроется режим редактирования. Впиши **название** и **описание**.
3. Выбери предмет для 3D-просмотра:
   * **Из руки** — положи нужный предмет в *другую* руку (не в ту, где экспонат). Копируется предмет целиком,
     вместе с NBT, поэтому кастомные предметы (CustomModelData из ресурспака, зелья, головы и т.д.) выглядят как надо.
   * **Выбрать...** — сетка всех предметов игры с поиском по названию/id (без NBT).
4. **Сохранить**. Дальше экспонат выглядит в инвентаре, руке и на земле как записанный в него предмет,
   а называется так, как ты его назвал.

## Управление при осмотре
ЛКМ + движение — вращать · Колесо над предметом — масштаб · R — сбросить · Колесо над описанием — прокрутка · Esc — закрыть.

## Выдача игрокам
Рецептов и лута нет. Остальным выдавай командой / командным блоком (NBT сохраняется в предмете):

    /give @p itemview:exhibit{Title:"Торнадо в бутылке",Desc:"Внутри мензурки медленно вращается крошечный вихрь.",Shown:{id:"minecraft:potion",Count:1b}}

Править экспонат может только игрок в креативе (проверяется на сервере). Остальные могут только смотреть.

## Важно
* Всё хранится в самом предмете (название, текст, стек предмета) — внешних файлов нет, у всех игроков работает одинаково.
* Если предмет для просмотра кастомный (ресурспак), у игроков должен стоять тот же ресурспак.
* Звуки и фоновая атмосфера — те же, что в моде на записки (`assets/itemview/sounds/*.ogg`, можно заменить).
